定义棋盘与格子状态

认识井字棋工程布局已经指出井字棋动态库的头文件位置。这一章只处理棋盘：它如何定位格子、保存状态、把坐标换算成数组下标，以及拒绝无效访问。本章的代码写在头文件 board.h 和源文件 board.cpp 里。

认识棋盘格子

每个棋盘格子由一个坐标定位，并保存一种状态。

定义坐标范围

CellPosition 用行和列定位棋盘格子，声明在 board.h 里。

board.h
/// 棋盘的行数。
inline constexpr int kRows = 3;
/// 棋盘的列数。
inline constexpr int kCols = 3;
/// 棋盘包含的格子总数。
inline constexpr int kCellCount = kRows * kCols;

/// 表示棋盘格子的行列坐标。
/// 行和列从 0 开始，默认构造的坐标是 (0, 0)。
struct CellPosition {
  int row = 0;  ///< 行坐标。
  int col = 0;  ///< 列坐标。
};

CellPosition 把坐标交给 Board，负数和行列为 3 的位置都会被拒绝。下面的图标出可用的 (row, col)。左上角是 (0, 0)，行向下增加，列向右增加。

行向下、列向右，左上角是 (0, 0)

区分空格与棋子

每个棋盘格子保存 board.h 中 CellState 的三种取值之一。

board.h
/// 棋盘格子的状态。
enum class CellState : std::uint8_t {
  kEmpty = 0,   ///< 空格。
  kCross = 1,   ///< X 棋子。
  kNought = 2,  ///< O 棋子。
};

空格可以落 X 或 O，终端把后两种状态显示为对应字母。

读写棋盘格子

Board 对内用一个数组和一次下标换算存放九个格子，对外只暴露检查后的读写入口。

用数组存放九个格子

九个棋盘格子存放在 board.h 私有段的一个数组里。

board.h
 private:
  /// 将二维坐标转换为一维索引。
  [[nodiscard]] static std::size_t ToFlatIndex(CellPosition position) noexcept;

  // 棋盘格子的存储数组，按行依次存放。
  std::array<CellState, static_cast<std::size_t>(kCellCount)> cells_{};

数组的类型把长度 kCellCount 直接写进类型本身：棋盘在编译期就固定为 9 格，代码里写不出其他长度的 cells_。井字棋的格子数从规则上就不会增减，std::array 的固定长度正好把这条规则固化下来，不需要能自动变长的容器。

换算一维下标

数组只用一个下标编号格子，Board 用一行公式把行列坐标换算成它，定义见 board.cpp。

board.cpp
// 先跳过前面的整行，再加上列偏移，得到一维索引。
std::size_t Board::ToFlatIndex(CellPosition position) noexcept {
  return (static_cast<std::size_t>(position.row) * kCols) +
         static_cast<std::size_t>(position.col);
}

公式是 row * kCols + col：乘法跳过这一行前面的整行，每行有 kCols 个格子，代入 (1, 2) 得到 1 * 3 + 2 = 5。

换算只发生在 Board 内部，ToFlatIndex 也声明在私有段，调用方始终只传行列坐标。下面的图把 cells_ 的九个下标排成一行：第 0 行占下标 0–2，第 1 行占 3–5，第 2 行占 6–8，加粗的 5 号位置就是 (1, 2) 的换算结果。

检查坐标后访问

每个读写入口都先经过 IsValidPosition 检查，声明在 board.h。

board.h
/// 表示井字棋的棋盘。
/// 提供读取格子状态、放置棋子和检查棋盘是否已满的功能。
class Board {
 public:
  /// 检查坐标是否在棋盘范围内。
  [[nodiscard]] static bool IsValidPosition(CellPosition position) noexcept;

  /// 构造函数：创建一个所有格子均为空的棋盘。
  Board() = default;

  /// 获取指定坐标处的格子状态。
  [[nodiscard]] CellState GetCellState(CellPosition position) const;

  /// 在指定坐标放置棋子。
  [[nodiscard]] bool PlacePiece(CellPosition position, CellState state);

  /// 检查棋盘是否已满。
  [[nodiscard]] bool IsFull() const noexcept;

摘录里的标注服务于调用方：[[nodiscard]] 表示忽略返回值就是逻辑错误。IsValidPosition 和 IsFull 标注 noexcept，承诺不会抛出异常。摘录只保留每个函数的概述行，参数、返回值与异常的 @param、@return、@throw 标签见源文件。

这些声明的函数体都写在 board.cpp 里，IsValidPosition 的定义就是同一条坐标边界：

board.cpp
bool Board::IsValidPosition(CellPosition position) noexcept {
  return (position.row >= 0 && position.row < kRows) &&
         (position.col >= 0 && position.col < kCols);
}

调用方只给出坐标和要写入的状态，数组和下标换算都留在 Board 私有段。Board 完成格子读写，Game 在下一章决定轮到谁落子、何时获胜和何时平局。

常见错误

绕过棋盘直接计算数组位置

调用方自己计算下标时，很容易漏掉负坐标或上界检查。

  • 把坐标交给 Board。它会拒绝无效位置。
  • 换算与存储都留在 Board 私有段，调用方不复制公式。

把空状态当成一次落子

CellState::kEmpty 只表示还未落子，不能写入为新的落子状态。

  • 用 kCross 或 kNought 调用 PlacePiece。

自测问题

先不要展开答案，试着自己把回答完整说出来，再展开对照。说不出来的部分，回到对应小节对照正文。

  1. 为什么行号 -1 和 3 都会被拒绝？

    查看答案

    Board::IsValidPosition 要求行号从 0 到 kRows - 1。kRows 是 3，所以 -1 和 3 都不属于棋盘。

  2. 向已有 X 的格子再落一次 O，棋盘会变吗？

    查看答案

    不会。PlacePiece 在格子已经占用时返回假，棋盘保持不变。

  3. (1, 2) 对应数组的哪个位置？

    查看答案

    ToFlatIndex 按 row * kCols + col 换算：1 * 3 + 2 = 5，即下标 5。

  4. 为什么用 std::array 存放九个格子？

    查看答案

    格子数固定为 9，长度 kCellCount 直接写进类型，编译期就确定，代码里写不出其他长度的数组。不需要能自动变长的容器。
