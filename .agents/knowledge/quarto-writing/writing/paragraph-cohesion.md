# 段落衔接与结构模型

起因是各章行文缺乏统一的衔接方式。中文写作对段落衔接的抽象描述分三层：文章级结构方式（总—分—总、并列式、递进式、对照式）、段落展开方式（递进式按步骤或因果层层推进，并列式枚举无先后关系的要点）、段间衔接手段（过渡词、过渡句、过渡段实现承上启下，首尾照应收束全文）。本文件把它落成 `content/**/*.qmd` 的执行标准；段内降噪与删改的通用做法见 `writing-quarto` 技能 `.agents/skills/writing-quarto/references/zh/writing-principles.md`。

## 章级：总—分—总

- **总起**：无标题引言承接上一章并给出本章任务，规则见标识 `bg-chapter-page-pattern-v1` 的知识文件。
- **分述**：正文 `##` 序列沿一条主线递进展开，每个 `##` 是一个可验证结果。
- **收束**：本章回顾照应引言提出的任务，句式「你已经能 <能力>。下一章 <预告>。」；首尾照应要求回顾能对上引言的承诺，不引入新概念。
- 尚未实现的规划页允许暂缺自测与回顾，此时由最后一个正文节的边界句收束（说明什么留到后续章节）；该章真实实现时补齐收束位。

## 节内：递进式为默认，并列式处理枚举

- 有先后或因果的内容用递进式展开：概念 → 示例 → 操作 → 验证（顺序依据见标识 `bg-chapter-page-pattern-v1` 的知识文件），段落顺序与执行顺序一致。
- 无先后关系的要点（边界清单、原则枚举）用并列式：并列内容优先成列表，不强行排序成递进（列表选择规则见标识 `bg-paragraph-list-style-v1` 的知识文件）。
- 同一小节内不混用：一条主线递进到底；并列枚举整体作为一个环节嵌在递进中。

## 段间：过渡句只在话题切换处

- 需要过渡的位置：段落话题或对象发生切换时（上一段讲 A 命令，下一段讲 B 命令；上一节配置，下一节运行）。同一段内句子推进、或下一段直接继续当前对象时，不加过渡。
- 形式：一句，放在新段段首，先接住上文（点明与上段的关系或结果），再引出本段中心。范例（02 章注册冒烟测试节首句）：「可执行目标之外，同一份构建规则还注册了本章唯一的自动化检查」——前半句接住上文的可执行目标，后半句引出新对象。
- 边界：过渡句服务主线判断，不复述标题结构。「接下来先看…再看…然后…」式导航复述段仍然禁止（规则见标识 `bg-paragraph-list-style-v1` 的知识文件）；`##` 开头承接不超过 2 句、`###` 不超过 1 句（规则见标识 `bg-chapter-page-pattern-v1` 的知识文件）。
- 下一节首句同时是上一节的承接位：写完上一节结尾后检查下一节首句是否接住读者，不在上一节尾部再补预告句（与凑字数禁令同源）。
- 相邻段落同义合并：相邻两段各自换一种说法讲同一事实时合并为一段，由后段的机制或结论接住前段的对象；合并后其余段落、列表和 Callout 不得再以第三种说法复述该事实。改写对照见标识 `bg-chinese-style-cases-v1` 的知识文件。
- 相邻两段不得各成独立说明书：第一段讲工具、第二段讲目录而彼此无衔接时，第二段段首要接住第一段的对象（工具基线 → 这些工具在编号目录上如何使用）；只删不接，两段仍然是两个条目。改写对照见标识 `bg-chinese-style-cases-v1` 的知识文件。
- 表格与对照表前必须有承接句：先写各对象在做什么，再用一句关系句引出表格（如「配置改计划，构建消费计划」），禁用「X 与 Y 是两个容易混淆的词：」式元标签开场；表后一句给读者该取走的结论（块级闭环见标识 `bg-qmd-element-cases-v1` 的知识文件）。

## 小节标题与正文对齐

- 小节标题、首句和正文指向同一个动作或对象；标题说「做什么」，正文就只写怎么做、看到什么算成功。
- 操作小节（如「运行一键脚本」）只保留动作、顺序与可见结果。「为何不跳过某步 / 幂等 / 配置漂移」类工程取舍，删除后不影响首次跑通与验收的，不进该节正文；确需保留时由代码注释或排查节承担。
- 跨节复述同一取舍视为标题离题的变体：该内容归属最贴合的节（如「修改 CMakeLists 后行为没变」），其余位置只保留一句或链接。

## 与其他规则的边界

- 块级前后闭环（引言 → 块 → 结尾 → Callout）见标识 `bg-qmd-element-cases-v1` 的知识文件；本文件管段落与小节之间的衔接，不重复块内规则。
- 多命令代码块后的逐条讲解用 `**标识符**：一句职责` 无序列表，规则见标识 `bg-paragraph-list-style-v1` 的知识文件。
- 小节承接正文权重与盒子密度见标识 `bg-section-focus-density-v1` 的知识文件。
