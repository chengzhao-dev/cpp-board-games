# content 篇幅的 token 预算

起因是 02 章连环出现凑字数句、复述导航段和长注释片段：逐条句式规则拦得住具体坏句，拦不住「每一句都合规但整页过量」。本预算只约束 `index.qmd` 与 `content/**/*.qmd` 的读者正文，由 `writing-quarto` 技能的 `verify_content.py` 第 3 查「篇幅预算」自动执行，超限即为失败。`.agents/**`、`AGENTS.md` 与源代码不套用本表；它们继续遵循各自的 Agent、技能与代码检查规则。

## 计数口径

估算 token = 中日韩字符数 × 1.5 + 其他字符数 ÷ 4。公式对主流分词器（GLM、Claude、GPT）取保守上界，只用于预算比较，不声称等于真实 token 数。

- **计入**：正文、标题、列表、表格、Callout 与链接锚文本。
- **不计入**：YAML frontmatter、链接 URL、代码围栏（`{.cpp}`、`{.text}`、bash 等）全文、`{mermaid}` 图表全文、`{python}` 可执行单元全文。逐字代码与图表是机器寻址或视觉对象，读者扫读时整体跳过；token 预算度量的是读者逐句读过的正文当量。
- 代码与图表不计 token 不等于免检：它们仍受分层的行数上限与注释连续行检查约束（见下表）。
- Markdown 链接只计入锚文本，URL 不计入：GitHub 绝对链接的 URL 是机器寻址字符串，计入会挤占正文预算并与「仓库内一律 GitHub 绝对链接」的约定冲突；`verify_content.py` 在计数前剥离链接 URL，锚文本照常计入。
- 字符数按 Unicode 字符计：汉字、全角标点各算 1 个字符，归入中日韩一侧。
- 节导语口径：标题之后、首个代码块/列表/表格/引用/盒子（div）之前的连续正文；空行只分段，不结束导语。导语内链接只计锚文本，URL 不计入。
- 引用块口径：连续 `>` 行合并为一块计数，链接只计锚文本；Callout 盒子（`:::`）不是引用块，按其自身层级计入所属分节。

## 分层上限

| 层级 | 上限 |
| --- | --- |
| 整章（frontmatter 外全部内容，只含计入部分） | 5000 token |
| 无标题引言（首个 `##` 之前） | 400 token |
| 单个 `##`（含其下全部 `###`） | 1800 token |
| 单个 `###`（含其代码块） | 600 token |
| 任务级 `##` 数量 | 通常不超过 4 个；按独立任务划分，不足时不凑数 |
| 每个 `##` 下 `###` 数量 | 4 个 |
| 普通代码块（围栏内内容行） | 20 行 |
| `{mermaid}` 图表块 | 40 行 |
| `{python}` 可执行单元（坐标图等） | 30 行 |
| 单个正文段落（代码块、表格、列表与标题之外的连续文本段） | 220 token |
| `##` 节导语（标题后、首个代码块/列表/表格/引用/盒子前） | 120 token 且 ≤2 句 |
| `###` 节导语（同口径，到首个盒子/代码块/列表前） | 80 token 且 ≤1 句 |
| 单个 `>` 引用块（连续引用行合并计） | 80 token |
| 代码片段内注释 | 每处 ≤2 行，单行 ≤40 字；命令型片段每条命令保留一行意图注释 |

`{python}` 可执行单元应只含助手调用，绘图逻辑在共享助手库（见标识 `bg-coords-diagram-v1` 的知识文件）；超出 30 行说明把绘图逻辑内联进了正文，属于结构违规。

数字依据：没有规定章节字数的权威国标（GB/T 7713《科技报告编写规则》只管结构格式）；技术写作社区实践是单节对应 3-5 分钟阅读（约 1500-3000 字）、单个功能模块 800-1200 字，超限优先拆分。按 CJK×1.5 换算，整章 5000 token 约合 3300 汉字的正文当量，是「一节一件事、一章四节左右」的自然边界。

## 执行方式

- `verify_content.py` 第 3 查按上表逐文件、逐节、逐代码块、逐正文段落核对，超限即整体失败；限额调整只改该脚本的常量与本表，两处必须同步。
- 根目录 `index.qmd` 与 `content/<game>/index.qmd`（YAML 含 `body-classes: index-page`）是着陆页：短引言与卡片网格不是章节引言，只核对整章总量与代码块限额，不做引言、分节和任务级 `##` 数量限制。
- 任务级 `##` 通常不超过 4 个；`常见错误`、`自测问题`、`本章回顾`是固定收尾，不计入任务级数量，但仍执行各自的结构检查。标题数量是页面结构约束，不是把独立任务机械压成 `###` 的理由；只有独立动作、观察或验证结果才使用 `###`。第一章可以没有「常见错误」。
- 本规则只限制 QMD 读者正文。`.agents/**`、`AGENTS.md`、C++、CMake、Bash 和 Python 文件不参与任务级标题数量或 QMD 正文 token 检查。
- 章节页面类型由 `verify_content.py` 根据着陆页标记和固定收尾标题判定；无法自动判断的页面保留人工审阅。
- 结构性规则（引言构成、`###` 数量）同时受标识 `bg-chapter-page-pattern-v1` 的知识文件约束；本表提供量化兜底。
- 接近上限不是目标：预算是硬顶，内容仍按凑字数禁令与密度规则精简（见标识 `bg-paragraph-list-style-v1` 的知识文件）。
